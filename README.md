# Attendance-tracker

**A menu-driven Student Attendance Management System developed using Python as part of the Semester 1 Python Programming Project.

The application records daily student attendance, calculates attendance percentages, identifies students whose attendance is below 75%, and stores attendance records in a text file for future use.

## Features

- **Add Students:** Register new students in the attendance system.
- **Mark Attendance:** Record daily attendance using `P` (Present) or `A` (Absent).
- **Attendance Register:** Display attendance records in a tabular format.
- **Attendance Percentage:** Calculate the attendance percentage of each student.
- **Attendance Shortage:** Identify students whose attendance is below 75%.
- **Daily Absentees:** Display students absent on a selected day.
- **View Students:** Display all registered students.
- **File Handling:** Save attendance records in a `.txt` file and load them when the program starts.
- **Late Student Registration:** Newly added students receive `-` for previously recorded days.
- **Input Validation:** Handle invalid attendance marks and menu choices.
